概要：
	Yuki's Game Light は、ゲームワールド内の画面を明るくすることに特化した VRChat アバター用の機能プラグインです。
	複数のライトによる照明と画面処理を組み合わせ、元の色合いをできる限り維持しながら、暗い場所や霧の中での視認性を向上させます。

	— — Yuki_Tyan

注意事項：
	本プラグインは Write Defaults Off を前提として制作されています。
	使用中にライトが異常にちらつく場合は、本プラグインに関連するアニメーションの Write Defaults Off 設定が変更されていないか確認してください。

	本プラグイン内のオブジェクト名を勝手に変更しないでください。
	本プラグインのアニメーターは、あらかじめ設定されたオブジェクト名と階層構造を前提として動作しています。
	オブジェクト名を変更すると、アニメーターが正常に動作しなくなったり、完全に機能しなくなる場合があります。

	元のオブジェクトの階層構造と名前を変更しない限り、独自のオブジェクト、アニメーション、その他の機能を自由に追加して、本プラグインを拡張することができます。

使用方法：
	導入するだけですぐに使用できます。
	プレハブをアバターのルート直下にドラッグ＆ドロップするだけで、追加の設定は必要ありません。

機能：
	スポットライト：
		円錐状の光を前方に照射し、アバターの正面を明るくします。

	180° 方向光：
		方向光は距離による明るさの減衰がありません。
		2つの方向光を使用し、それぞれを立方体空間の対角方向に向けることで、周囲の大部分の方向を照らします。
		ただし、光源の方向が限られているため、アバターの周囲には照らすことのできない範囲が残ります。

	360° 方向光：
		4つの方向光を異なる方向に配置し、周囲全体をカバーすることで、あらゆる方向から光を照射します。
		4つの方向光を同時に使用するため、パフォーマンスへの負荷が増加し、一部のデバイスやワールドではカクつきが発生する場合があります。

	霧軽減：
		画面処理によって霧による画面の暗さを軽減し、元の色合いをできる限り維持しながら明るくします。
		この機能ではシェーダーを使用して画面の色を処理します。
		まず色の明度を抽出してガンマ補正による明るさの調整を行い、その後、元の色の色度を基に色を復元することで、明るくした際に発生しやすい灰色がかった見た目や色の歪みを抑えます。
		注意：この機能は霧そのものを除去するものではありません。
		霧によって暗くなった画面を明るくすることで、霧の中にある物体を見分けやすくする機能です。

	霧軽減ガンマ補正：
		霧軽減によるガンマ補正の強さを設定します。
		値を高くするほど、霧によって暗くなった部分がより明るくなります。

	霧軽減カラー彩度：
		霧軽減後の色の彩度を調整します。
		彩度を上げることで、明るくした際に発生する灰色がかった見た目を抑え、色をより鮮やかにして見分けやすくすることができます。
		
	明るさの記憶：
		3種類のライトモードには、それぞれ独立した明るさの記憶機能があります。
		スポットライト、180°方向光、360°方向光は、それぞれ個別に明るさの設定を記憶します。ライトモードを切り替えると、そのモードで最後に使用した明るさが自動的に復元されるため、切り替えるたびに再調整する必要はありません。
		
	知らない人から自動で非表示：
		ライトの明るさが10%を超えると、「知らない人から非表示」が自動的に有効になります。
		明るさが高い場合、ライトは知らない人から見えなくなり、他のプレイヤーへの不要な視覚的な影響を軽減します。
