概要：
    Yuki's Game Light は、ゲームワールドの画面を明るくすることに重点を置いた VRChat Avatar 用機能プラグインです。
    複数のライトの組み合わせと画面処理によって、元の画面の色彩をできる限り維持しながら、暗い場所や霧の中のシーンの視認性を向上させます。

        — — Yuki_Tyan

注意事項：
    本プラグインは Write Defaults Off を前提として制作されています。使用中にライトが異常にちらつく場合は、本プラグインに関連するアニメーションの Write Defaults Off 設定が変更されていないか確認してください。
    本プラグイン内のオブジェクト名を任意に変更しないでください。本プラグインの Animator はあらかじめ設定されたオブジェクト名と構造に依存しています。オブジェクト名を変更すると、Animator が正常に動作しなくなったり、完全に機能しなくなったりする可能性があります。
    元のオブジェクト構造と名前を変更しない限り、独自のオブジェクト、アニメーション、その他の機能を自由に追加して、本プラグインの機能を拡張することができます。

使用方法：
    依存パッケージ：Modular Avatar
    Prefab を Avatar のルートノードの下に直接ドラッグするだけで使用できます。追加設定は必要ありません。

機能：
    スポットライト：
        円錐形の光線で前方の範囲を照らし、通常は Avatar の正面の明るさを向上させるために使用します。

    180° ディレクショナルライト：
        ディレクショナルライトの明るさは距離によって減衰しません。
        2つのディレクショナルライトで構成され、立方体空間の対角線方向に角度を調整することで、ほとんどの角度をカバーできますが、照らすことのできない角度が一周分存在します。

    360° ディレクショナルライト：
        4つのディレクショナルライトで構成され、それぞれのライトの間の角度は120°です。空間全体をカバーし、あらゆる方向から照らすことができます。4つのディレクショナルライトを同時に使用するため、一部のシーンでは動作が重くなる場合があります。

    霧軽減：
        シェーダーによって画面のピクセルを処理し、霧による画面の暗化効果を弱めます。元の色彩をできる限り維持しながら明るさを向上させ、過度に高い明るさによるグレアの発生を防ぎます。

    霧軽減 ガンマ：
        霧軽減の Gamma 強度を調整します。ホイールの数値が高いほど、画面の明るさがより強くなります。

    霧軽減 カラー彩度：
        霧軽減によって明るくした後の色の彩度を調整します。彩度を上げることで、画面を明るくした際に発生する灰白色のような見え方を軽減し、物体の色をより鮮明にして、識別しやすくします。

    明るさメモリ：
        3種類のライトモードにはそれぞれ独立した明るさメモリがあります。ライトモードを切り替えると、前回設定した明るさが自動的に復元されます。

    明るさ分離：
        Local、Friends Only、Strangers には、それぞれ異なる3つの値を使用した Blend Tree を設定し、他のプレイヤーへの影響が大きくなりすぎないようにします。
