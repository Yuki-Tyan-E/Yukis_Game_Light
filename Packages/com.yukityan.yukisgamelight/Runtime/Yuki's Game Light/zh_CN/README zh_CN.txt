简介：
	Yuki's Game Light 是一款专注于提升游戏地图画面亮度的 VRChat Avatar 功能插件。
	通过多种灯光组合与画面处理方式，在尽可能保持原有画面色彩的情况下，改善较暗区域以及雾中场景的可见度。

		— — Yuki_Tyan

注意事项：
	本插件基于 Write Defaults Off 的方式制作。如果使用过程中出现灯光频闪的异常情况，请检查本插件相关动画中的 Write Defaults Off 设置是否被修改。
	请勿随意修改本插件内对象的名称。插件的动画机依赖于预设的对象名称与结构，任意修改对象名称可能导致动画机无法正常工作，甚至完全失效。
	在不修改原有对象结构与名称的前提下，可以自由添加你自己的对象、动画或其他功能，以扩展本插件的功能。

使用说明：
	依赖包：Modular Avatar
	将预制件直接拖拽到 Avatar 根节点下即可，无需进行额外配置。

功能说明：
	聚光灯：
		圆锥形光束照亮前方区域，通常用于提高 Avatar 正前方的亮度。
		
	180° 定向光：
		定向光的亮度不会随距离衰减。
		由 2 个定向光组成，并调整角度至立方体空间的对角线，可以覆盖大部分角度，但会存在一圈无法被照亮的角度。

	360° 定向光：
		由 4 个定向光组成，每个光源之间的夹角均为120°，可以覆盖整个空间，从各个角度提供灯光。由于同时使用 4 个定向光，在部分场景中可能会卡顿。

	雾透提亮：
		通过着色器处理屏幕像素，减弱迷雾造成的画面变暗效果，在提升亮度的同时尽可能保持原有色彩，并阻止超高亮度产生眩光。

	雾透伽马提亮：
		控制雾透提亮的 Gamma 强度。轮盘数值越高，画面提亮效果越明显。

	雾透颜色饱和度：
		控制雾透提亮后的颜色饱和度。提高饱和度可以减少画面提亮后出现的灰白感，使物体的颜色更加鲜明、更容易分辨。
		
	亮度记忆：
		三种灯光模式均拥有独立的亮度记忆，切换灯光模式时会自动恢复上一次设置的亮度。
		
	亮度分离：
		本地、仅好友、陌生人，采用3个不同数值的亮度混合树，避免过于影响其他玩家。
